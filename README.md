# AVE Canvas Analytics Pro 2.1 - Full corregida

Aplicación Streamlit para seguimiento académico desde Canvas API.

## Incluye
- Dashboard ejecutivo.
- Riesgo de desconexión.
- Cumplimiento de horas mínimas.
- Entregas por estudiante.
- Vista por módulos y entregables.
- Matriz estudiante vs entregable.
- Mensajería Canvas con validación de destinatarios.
- Modo prueba con profesores/TA.
- Reportes Excel y PDF.
- Bitácora local SQLite.

## Uso local
1. Instalar Python 3.10+.
2. Ejecutar `INICIAR_APP_WINDOWS.bat`.
3. Ingresar URL Canvas y token.

## Streamlit Cloud
Subir todos los archivos al repositorio y reiniciar la app.
